Hubungkan ke Google Drive

Aplikasi ini menyimpan file di Google Drive. Sekali saja, buat OAuth Client ID di Google Cloud lalu tempelkan di bawah.

  1. Buka Google Cloud Console dengan email yang Drive-nya mau dipakai, buat project baru.
  2. Di APIs & Services → Library, aktifkan Google Drive API.
  3. Di OAuth consent screen, pilih External, isi nama aplikasi, lalu tambahkan email Anda sebagai Test user.
  4. Di Credentials → Create credentials → OAuth client ID, pilih Web application. Pada Authorized JavaScript origins isi https://vena.web.id.
  5. Salin Client ID yang muncul, tempel di sini.

Tersimpan di browser ini saja. Agar berlaku di semua perangkat, isi juga di file config.js.

            Pasang Vena di layar utama

            1. Ketuk tombol Bagikan di bilah bawah Safari.
            2. Gulir ke bawah, pilih Tambahkan ke Layar Utama.
            3. Ketuk Tambah di pojok kanan atas.

            Di iPhone dan iPad, gunakan Safari. Setelah terpasang, buka Vena dari ikonnya di layar utama.

            1. Buka menu browser (⋮ di kanan atas).
            2. Pilih Instal Vena…, Instal aplikasi, atau Tambahkan ke layar utama.
            3. Klik Instal.

            Di komputer, bisa juga lewat ikon pasang (⊕) di ujung kanan bilah alamat Chrome atau Edge. Kalau pilihan itu belum muncul, muat ulang halaman sekali (F5) lalu coba lagi.
